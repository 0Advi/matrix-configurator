## 4. Runtime recommendation

**Use the in-app interpreter (`runtime.py`) for custom modules now. SpiffWorkflow and Operaton come later.**
Both engines ran the same generated BPMN module correctly. Neither handles Matrix authorization (tiers,
delegation, SoD, observer, admin bypass) or field validation, so that stays our code either way. Other costs:

* their gate expressions are engine-specific: JUEL in Operaton, Python in SpiffWorkflow;
* SpiffWorkflow is LGPL-3.0;
* Operaton is a second runtime: an 815 MB image, about 0.5 GB of RAM, its own database and identity model,
  and a REST API that is open by default.

Revisit an engine only when parallel branches, timers/escalations or customer BPMN become requirements.

## 6. Cross-workstream findings (please route them)

1. **F2 guard vs production admin bypass.** F2's `module_approvals` guard refuses a `submitted` verdict from
   a business admin acting on an executive/supervisor step.
   * Recommended: F4 builds the runtime with `admin_override=False` for custom modules.
   * Alternative: F2 relaxes the guard and the `override` flag is kept in `audit_logs.provenance`.
2. **Admin-only stages with fields** (Design GFC, PEx admin review, Launch admin review) would also violate
   F2's guard. `approval_row()` records these as `approved`.
3. **F2's `module_records` has no column for runtime state** (step, pass, verdicts, hash chain). Proposal: add
   `runtime_state jsonb`.
4. **Built-in facts must be cumulative.** `reached[module]` has to list every outcome reached so far, not
   only the current status from `site_module_outcomes`.
5. **CSP.** rjsf's ajv8 validator needs `'unsafe-eval'`. This was tested: when code generation is disallowed,
   every submission fails. That is fine on localhost and under today's Report-Only CSP. Swap the validator
   before enforcing the CSP (for-F4 §2).
6. **Roll-up vocabulary.** With v5 yes/no/n/a only, production Legal and NSO **park**: 8 fields need an
   `outcome_map`. The wizard templates also mark text, file and number fields as `affects_outcome`, which
   cannot be scored.
