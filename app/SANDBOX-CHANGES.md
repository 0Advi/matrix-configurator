### Production notes (NOT applied — required before this ships outside localhost)

- `vercel.json` sends `X-Frame-Options: DENY` and a (report-only) `frame-ancestors 'none'` for every path: the portal's
  same-origin iframe of `/configurator/` would be **blocked** in production. Needs `SAMEORIGIN` / `frame-ancestors 'self'`
  for `/configurator/(.*)` (and `/admin`). Its CSP would also need `'unsafe-eval'` for the dc-runtime and ajv (`new Function`)
  when enforced — or precompiled validators / a non-eval validator (F3 for-F4 §2).
- `/cfg` exists only on the Vite dev server (proxy to the localhost configurator server). A deployed build has no design-time
  store; the configurator then keeps drafts in the browser (its local mode). Publishing to the app still works.
- The workspace JWT stays in `sessionStorage` (existing behaviour); the embedded configurator page is same-origin, so it is
  trusted code just like the rest of the bundle.
